# TaskBox v0.1 — URL共有型タスクボード

Next.js + Supabase による、ログイン不要の共有タスク管理Webアプリです。

## 機能
- プロジェクトごとにランダムな個別共有URLを発行
- タスク・グループの作成、編集、削除、色変更
- PC向けドラッグ＆ドロップによる移動・並び替え
- 横並び、縦並び、グリッド、自由配置
- Supabase PostgreSQLへの永続保存、約3秒間隔の更新確認
- 更新競合時は409を返して上書きを防止
- 全グループ・全タスクを展開した画像のプレビューと保存（通常PNG、大きなボードはSVG）

## 全体の進捗を画像に保存
1. 共有URLでプロジェクトを開き、「同期済み」を確認します。
2. 上部の「画像を保存」を押します。
3. プレビューでグループ数・タスク数を確認し、「PNGを保存」を押します。

画像にはプロジェクト名、作成日時、グループ名・件数、全タスクの名前・詳細・色を含めます。
保存用にグループを最大4列で整列し、長い名前と詳細は改行します。現在のスクロール位置や自由配置での重なりに左右されません。
元のレイアウト・タスク・並び順は変更しません。処理は端末内で完結し、画像作成のための外部APIや追加料金はありません。

大きなボードは、文字を切ったり極端に縮小したりせずSVG画像で保存します。
PNG化は縦横4096px以内・1600万画素以内に抑え、通常は2倍解像度、必要に応じて等倍で作成します。
対応するスマホには「共有・写真に保存」も表示します。保存先や共有メニューは端末・ブラウザによって異なります。

## 開発環境での確認
- `npm test`：全件出力、文字の折り返し、SVGのエスケープ、空データ、データ非破壊など6件。
- `npm run build`：Next.jsビルドと型チェック。
- 画像保存は架空データを使ったChromeで確認。PC幅・スマホ相当幅、長文、300件のSVG出力を確認しました。スマホ実機のダウンロード／共有・写真保存は未確認です。

## セットアップ
1. Supabaseでプロジェクトを作り、SQL Editorで `supabase/schema.sql` を実行。
2. `.env.example` を `.env.local` にコピーし、Supabase Project URLとservice_roleキーを設定。
3. `npm install` と `npm run dev` を実行。
4. VercelにGitHubリポジトリをインポート。
5. Vercelに `SUPABASE_URL` と `SUPABASE_SERVICE_ROLE_KEY` を環境変数として設定してデプロイ。
6. 2台の端末で同じ共有URLを開いて同期を確認。

## セキュリティと制限
- service_roleキーはサーバー環境変数のみ。GitHubやクライアントに公開しない。
- RLS有効、anonポリシーなし。共有URLを知っている人は全編集権限を持つ。
- URL失効・再発行、APIレート制限、監査ログ、バックアップは未実装。
- タスク登録数にUI上の固定上限はないが、APIのJSONサイズ制限などがある。
- 同期はWebSocketではなく3秒ポーリング。スマホのドラッグ操作は未検証。
- Vercelの公開版とSupabaseの稼働・テーブル構成は確認済み。本番データへの書き込み、2端末同期、スマホ実機テストは別途確認が必要です。
